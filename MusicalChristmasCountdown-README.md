# Holiday Magic Dashboard

A festive, self-contained single-file HTML dashboard featuring a live Christmas countdown, an interactive 12 Days of Christmas feature, and a built-in synthetic music player that plays a looping rendition of "Jingle Bells" using the Web Audio API.

## Features

* **Real-Time Christmas Countdown:** Automatically calculates and displays the days, hours, minutes, and seconds remaining until December 25th[cite: 1].
* **Dynamic 12 Days of Christmas Card:** Automatically cycles through curated holiday craft ideas and recipes from December 14th through December 25th, showing off-season or preview states the rest of the year[cite: 1].
* **Synthetic Web Audio Music Player:** Plays a looping version of "Jingle Bells" entirely through code with an on/off toggle button—no external audio files or downloads required[cite: 1].
* **Responsive & Standalone:** Built using pure HTML, CSS, and vanilla JavaScript in a single file, making it lightweight and easy to deploy anywhere[cite: 1].

## Quick Start

1. Download or copy the `ChristmasCountdown.html` file[cite: 1].
2. Double-click the file to open it instantly in any modern web browser.

## Hosting on GitHub Pages

To share this widget online or generate a QR code for it:

1. Create a public repository on [GitHub](https://github.com/)[cite: 1].
2. Upload `ChristmasCountdown.html` into your repository[cite: 1]. *(Note: If this is your main landing file, you can rename it to `index.html`).*
3. Go to your repository **Settings** > **Pages**[cite: 1].
4. Under **Build and deployment**, select your `main` branch and click **Save**[cite: 1].
5. Your live link will be available shortly at `https://<your-username>.github.io/<your-repo-name>/`[cite: 1].
