# Ambient Glow Clock

A small, elegant ambient clock designed to sit quietly on a screen.

### What it does

- Thin glowing clock trim and matching hands
- Color changes automatically each minute
- Transparent page background
- No controls or feature descriptions on the clock itself
- Responsive sizing for browser windows


### Live version

The clock can be published with GitHub Pages from the `main` branch using `index.html` as the site entry point.

### Sharing

The GitHub Pages URL can be shared directly with anyone who wants to open the clock in a browser.
